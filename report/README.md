# 科研实训总结报告

该目录是一套可直接上传到 Overleaf 的 XeLaTeX 工程。

## 编译

1. 将整个 `report` 目录上传到 Overleaf。
2. 在项目设置中将主文件设为 `main.tex`，编译器设为 XeLaTeX。
3. 参考文献使用 Biber；Overleaf 通常会自动执行所需的多轮编译。
4. 在 `main.tex` 顶部替换作者、学号、学校、实验室和指导教师占位符。

三张图均由 `figures` 目录中的 TikZ 源文件生成，不依赖外部图片。正文没有使用
`legacy` 目录中的历史实验数据，也没有把尚未执行的硬件自动校准写成实验结果。

## 提交前核对

- 根据最新一次测试重新填写“通过 / 失败 / 跳过”数量；
- 若取得硬件校准数据，再补充校准前后频谱和数据库指标；
- 检查学校是否要求指定封面、页眉页脚或参考文献格式；
- 确认最终 PDF 为 5--8 页且所有引用、公式和图号均可跳转。
